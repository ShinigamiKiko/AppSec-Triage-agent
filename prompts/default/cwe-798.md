## CWE-798 family — hardcoded credentials

This is the narrow class where the evidence is almost always *in the literal itself*. Judge the value, not the variable name.

### Rules the value must be checked against

| Pattern | Verdict direction | Note |
|---|---|---|
| `${VAR}`, `{{var}}`, `%VAR%`, `<VALUE>`, `@token@` | `false_positive` / `TEST_PLACEHOLDER` | Config templating resolved at deploy time. The secret is not in the repo. |
| `{service}_{suffix}` style composed strings | `false_positive` | Naming convention, not a credential. |
| Bare UUID (`8-4-4-4-12`) | `false_positive` / `IDENTIFIER_ONLY` | UUIDs are identifiers. |
| `trace_id`, `request_id`, `span_id`, `correlation_id` | `false_positive` / `IDENTIFIER_ONLY` | Observability values. |
| OAuth **Client ID** | `false_positive` / `IDENTIFIER_ONLY` | Client IDs are public by design. Only a **Client Secret** is a finding. |
| Public key, certificate body, key *fingerprint* | `false_positive` | Public material. `-----BEGIN PRIVATE KEY-----` is the opposite. |
| `AKIA…`, `ghp_…`, `xox[bap]-…`, `sk-…`, JWT, `BEGIN … PRIVATE KEY` | `confirmed` / `SECRET_VALUE` | Recognizable live-credential formats. Confirm even in a test file. |
| High-entropy literal ≥16 chars, no template markers, credential-named variable | `confirmed` / `SECRET_VALUE` | Quote the literal *and* the entropy signal as evidence. |
| Empty string, `""`, `null`, single word from a dictionary | `false_positive` | Not a usable credential. |
| Default vendor credential (`admin`/`admin`, `sa`/`""`) in **production** config | `confirmed` | In a test fixture: `false_positive`. Path decides. |

### Conflict resolution

If `known_secret_shape` fires **and** the path is a test directory → `confirmed`. A real key committed to a test file is a real key. Set `requires_human_review: true`.

If `template_expression` fires **and** `high_entropy_literal` fires on a different literal → do not close the finding. Return `unknown` and list which literal is ambiguous in `missing_information`.

If the credential is redacted in the payload (`***`, `[REDACTED]`) → `unknown`, `INSUFFICIENT_CONTEXT`. You cannot judge a value you were not shown.
